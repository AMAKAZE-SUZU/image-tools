メッセージカードメーカーの使い方

  1. サイズ(16:9 横長・1:1 正方形・4:5 縦長・9:16 縦長)を選びます。
  2. 背景画像を選びます。「タイル」にすると画像を敷き詰められ、暗さ・白さ・ぼかしも調整できます。
  3. 写真を選び、配置(左・右・なし)とフレーム(角丸・丸・チェキ風)を決めます。透明PNGを「フレームに重ねる画像」に入れると、リボンなどの飾りを上に乗せられます。
  4. メッセージと差出人を入力し、フォントと文字の色を選びます。手持ちのフォントファイル(.ttf / .otf)も使えます。
  5. 「このカードをPNGで保存」を押して完成です。

写真の切り抜き

「切り抜きの形」で写真の縦横比(正方形・縦長・横長・元の写真のまま・自由)を選べます。「切り抜きの拡大・縮小」(0が枠にぴったり、＋で拡大、−で縮小)と「切り抜く位置」で、写っている範囲を調整できます。縮小すると写真のまわりにフレームの色の余白ができます。拡大・縮小と位置はカードごとに覚えます。

たくさんまとめて作る

  1. 「まとめて作る」を開き、メッセージを「---」だけの行で区切って入力します。最後の行を「＠ミルクより」のように＠で始めると、そのカードの差出人になります。
  2. 「今のカードと入れ替えて作る」を押すと、メッセージの数だけカードができます。
  3. 写真を複数選ぶと、ファイル名順に1枚目のカードから入ります。
  4. プレビュー下の一覧でカードを選ぶと、1枚ずつ確認・修正できます。
  5. 「全部まとめてZIPで保存」で、全カードを一度に保存できます。

共通の設定と個別の設定

各設定の右にある「共通」を押すと「個別」になり、その設定をカードごとに変えられます。個別にした設定は、ほかのカードを調整しても変わりません。「個別」を押して共通に戻すと、今表示しているカードの値が全カード共通になります。最初は写真の配置・大きさ・傾き・切り抜き、差出人、文字色・縁取り色、文字の大きさが個別、それ以外が共通です。

作業中の状態は自動で保存され、次に開いたときに続きから始まります(写真と画像は保存されません)。「新しく始める」を押すと、全カードを消して初期値から始めます。

作ったものをファイルに保存する

「ファイルに保存」の「ファイルに書き出す」を押すと、全カードのメッセージと、背景・フォント・写真などの設定が1つのファイル(.json)に保存されます。「ファイルから読み込む」でそのファイルを選ぶと、書き出したときの状態に戻ります。画像も一緒に保存できるので、別のPCに移すときや、作ったものを残しておきたいときに使えます。

よく使う設定は、一番下の「今の設定を初期値にする」で保存しておくと、次回からその状態で始まります。スライダーをダブルクリックすると、その項目だけ初期値に戻ります。

アニメポスターメーカーの使い方

  1. 「作品」で大きさ(背景画像に合わせる・16:9・正方形・4:5・9:16)と長さ(秒)を決め、縦向きと横向きを切り替えるとレイヤーが自動で並べ直されます。続けて背景画像と背景の動き(ゆっくりズームなど)を選びます。
  2. 「レイヤー」で写真・画像や文字を追加し、プレビュー上でドラッグして配置します。右下の丸をつまむと大きさが変わります。ドラッグ中は作品やほかのレイヤーの端・中心にぴったり合います。「位置をそろえる」ボタンや、中心の座標・幅・高さ(px)の入力、矢印キーでの1px移動でも調整できます。
  3. 背景画像は「背景の大きさ・回転・位置」で調整できます。「プレビューで背景をドラッグして動かす」をオンにすると、プレビュー上で直接動かせます。
  4. レイヤーを選ぶと「アニメーション」で動きを付けられます。登場の動き(ふわっと・スライド・ぽよん・1文字ずつなど)、登場する時間、登場にかける時間、登場のあとも続く動き(ふわふわ・ゆらゆら・どきどき・くるくる・ちかちか)を選びます。「この動きを確認」でその部分だけ再生できます。
  5. 「エフェクト」でキラキラ・紙吹雪・ハートを重ねられます。
  6. 「▶ 再生」と時間のつまみで確認し、「MP4で保存」か「GIFで保存」を押して完成です。

続く動きとエフェクトは、作品の長さの中でちょうど繰り返すように作られるので、ループ再生してもつながります。「終わりに全体をフェードアウトする」をオンにすると、繰り返し再生がよりなめらかになります。

  • MP4の保存は、パソコンの Chrome か Edge がおすすめです。ブラウザによっては H.264 以外の形式になり、Twitter に投稿できないことがあります(そのときはメッセージで知らせます)。
  • GIFは色数が少ないため、写真のグラデーションが粗く見えることがあります。ファイルが重いときは「GIFの大きさ」や「なめらかさ」を下げてください。
  • 作業中の作品は画像も含めてブラウザに自動保存されます。別のPCに移すときは「ファイルに書き出す」を使ってください。

ポスターメーカーの使い方

1. テンプレートを作る

  1. 「テンプレートを作る」画面で、写真・画像・ロゴ・文字の枠をドラッグして配置します。右下の丸をつまむと大きさが変わり、実際のピクセル数も表示されます。
  2. 枠ごとに形・縁・影・回転を設定できます。ロゴなど全員共通の画像は「固定の画像」に入れておきます。
  3. ポスター全体に重ねる装飾フレーム(透明PNG)や、共通の背景もテンプレートに入れられます。

テンプレートは使っているブラウザに自動で保存されます。

2. ポスターを作る

  1. 「ポスターを作る」画面でテンプレートを選びます。
  2. 背景画像を選ぶと、その画像と同じサイズのポスターになります。
  3. 各枠に画像を入れ、必要なら文字を入力して「PNGで保存」します。

3. メンバー全員分をまとめて作る

  1. 写真のファイル名をメンバーの名前にしておきます(例:シフォン.png)。
  2. 文字枠に {名前} と入れておくと、ファイル名がそこに入ります。
  3. 「まとめて作成」で写真を複数選び、ボタンを押すと、全員分のポスターがZIPで保存されます。

テンプレートを人に渡す・別のPCで使う

「ファイルに書き出す」でテンプレートを画像ごと1つのファイルにできます。受け取った人は「ファイルから読み込む」で同じテンプレートを使えます。

注意点

  • 選んだ画像やテンプレートは、使っているブラウザの中だけで処理・保存されます。サーバーには送られません。
  • ブラウザのデータを消したり、シークレットウィンドウで使ったりすると、保存したテンプレートや初期値は消えます。大事なテンプレートは「ファイルに書き出す」で残しておいてください。
  • とても大きな背景画像(8000px級)は、スマホでは処理しきれないことがあります。その場合はPCで使ってください。
  • Chrome / Edge / Safari の新しいバージョンでの利用がおすすめです。
