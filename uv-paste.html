UVテクスチャ貼り付け

v1.1 ・ 2026-11-02

BlenderでエクスポートしたUVレイアウトの画像を下敷きにして、ロゴや柄をUVの区画(アイランド)にぴったり貼り付け、テクスチャとして保存します。モデルのファイルは使いません。画像はこのブラウザの中だけで処理され、外には送られません。

UVレイアウトの画像を、ここにドラッグ&ドロップしてください
(右の「UVレイアウトの画像」から選んでもOK。
「見本で試してみる」で使い方を試せます)

使い方
  1. BlenderでUVレイアウトを書き出して、読み込みます(下の説明)。
  2. 元のテクスチャを読み込みます(なくても作れます)。
  3. 「＋ 画像」で貼りたいロゴや柄を追加します。
  4. 「区画を選ぶ」にして、貼りたい場所の区画をクリックします。その形で切り抜かれます。
  5. 「画像を動かす」で、大きさ・位置・回転を合わせます。
  6. 「テクスチャをPNGで保存」して、Unity や Blender でテクスチャを差し替えます。
BlenderでUVレイアウトを書き出す方法

1. 「UV Editing」ワークスペースで、メッシュを編集モードにして全部選びます(Aキー)。

2. UVエディターのメニュー「UV」→「UV配置をエクスポート」(Export UV Layout)を選びます。

3. 「サイズ」を元のテクスチャと同じ(例:2048×2048)にし、形式は「PNG」、「塗りつぶしの不透明度」は 0.25 のままにします。選んでいない面も出したいときは「すべてのUV」にチェックを入れます。

塗りつぶしの不透明度を 0 にした画像や SVG でも使えます。

UVレイアウトとテクスチャ

貼る画像

下にあるものほど手前に表示されます。画像はここにドラッグ&ドロップしても追加できます。

    選んだものの設定

    貼る画像を追加すると、ここで設定できます。

    貼る区画

    選んだ区画をこの色で塗ります(区画を選ばないとテクスチャ全体)。「重ね方」を「乗算」や「カラー」にすると、元の模様や影を残したまま色を変えられます。

    保存

    書き出す大きさは、元のテクスチャと同じにしておくと差し替えが簡単です。作業(画像も含む)はこのブラウザに自動で保存されます。
